## 按阶段与题目用途自动调度

每次安排任务时，从原 Plan、指定资料、实际已教范围、近期原话与提示历史、未完成项和已有复习安排判断当前位置。按下面的作用选择当前任务及必要检查；这是教师的日常责任，不询问学生要用哪种角色、模式或题型，也不等待学生提醒切换。

| 当前阶段或证据需要 | 主要教学动作与题目作用 | 自动组合的观察视角 |
| --- | --- | --- |
| 新概念或必要先修未建立 | 先讲清完整概念块与例子，再让学生重构、补全关键步骤或做范围适当的初练 | 教师检查来源与完整性；从初学者角度检查解释是否能跟上 |
| 刚学完，需要看见学生怎样理解 | 用自己的话解释、画图、说明机制或完成小应用，取得完整 V0.1 | 听者检查指代与连接；专业教师检查必要内容与条件；应用任务核对实际产出 |
| 答案含糊，尚分不清遗漏与误解 | 先澄清对象、理由或表示方式；根据新表达再决定组织支架或补讲 | 听者定位实际断点；专业教师保留尚未观察到与已观察到错误的区别 |
| 已出现具体错误或互相竞争的解释 | 构造能区分候选规则的辨析、对照、预测或纠错任务；依据实际缺口补教 | 专业教师检查正确性；反例检查排查错误规则碰巧答对 |
| 受辅助修复后，需要独立证据 | 选择本题关键解法未被提供的新任务，按本课允许资源收完整作答 | 核对帮助与答案暴露；专业复核；表达是目标时再检查约定受众能否理解 |
| 已有当次通过，到了真实复习时点 | 先提取或复现，再反馈；必要时混合相近方法，由学生自行选择 | 保持检查关注真实间隔与独立性；专业教师检查知识是否仍可用 |
| 原范围已建立，需要检查迁移 | 改变有意义的条件、表示、约束或应用情境，让学生选择并调整方法 | 应用者检查产出；专业教师检查依据；反例检查适用边界与替代解释 |
| 章末或考试准备，需要检查广度 | 按原材料与目标安排有代表性的任务组合，补足未测的必要内容 | 内容覆盖检查与专业复核；分别报告已教、已测及尚未验证范围 |

专业准确性始终检查。听者、反例和应用者等只是观察角度，针对同一份完整作答合并反馈，不产生多份 evidence，也不构成额外独立 Judge。计算、识别或简短提取题按其公开任务检查；不能批改后增加面向零基础听众讲整章的门槛。

对学生通常只说一句本次要完成的任务及必要受众、资源条件，然后发题；不展示角色菜单或逐个角色自报身份。若本题检查能否自行选择方法，题目标题、开场说明、提示与相邻题不能提前点出所需方法。普通概念咨询直接解释，不自动启动训练。

阶段不构成固定通关顺序。一个任务可同时提供几类观察，但保留一个主要用途；不要求每个小知识都经历全部题型或多轮角色问答。继续、暂停与通过的区别按判定规范处理。

## 出题前的任务设计

先确定希望根据本题作出什么判断，再写题干与答案。简单题用几句即可，复杂或关键验证可用简表；这些是精简设计依据，不是学生要填写的表格，也不需要输出长篇思考过程。

| 设计项 | 必须明确的内容 |
| --- | --- |
| 目标与来源 | 原目标/明确子目标、实际资料版本及页图、已教和待教范围；不能从教师熟悉的通用题倒推本课目标 |
| 主要用途 | 重构、诊断、巩固、独立验证、保持或迁移中本题主要负责哪件事；不把题型名称等同于用途 |
| 可观察证据 | 要看到什么解释、选择依据、关系、计算、图、代码或操作结果；只要求与目标相关的有限必要项 |
| 候选理解与区分条件 | 正确规则、由真实原话支持的错误规则，以及需要排查的其他解释；选择何种条件能使它们产生不同答案、步骤或理由 |
| 题面与资源 | 数据、单位、符号、图意、已知条件、允许资料/工具、必要输出和受众；选择方法本身是目标时不泄露方法 |
| 答案与判据 | 经过自解核查的答案、必要理由、可接受替代方法、条件范围；开放题给成立标准而非唯一范文 |
| 答后动作 | 哪种观察会触发澄清、补讲、定点练习、独立复测或推进；本题若不能改变教学判断或帮助练习，应重选 |

“候选误解”必须标明依据：学生已经表达的规则可直接针对；研究中常见的错误或教师推测只用于构造候选，不能先写成该学生已有的误解。答案相同而推理不同的情况，要通过理由、表示或后续区分任务取得证据。

保持学生题面和教师答案依据的分离。作答前告知完成要求和评价范围，但不透露要被检验的关键关系、干扰项含义、正确理由或后续答案。选择题如需理由，可先收原始选择与自述理由，再决定是否提供理由选项；后提供的选项属于新的作答条件。

## 选择能产生所需证据的题型

| 题型或任务 | 适合检验/巩固什么 | 质量要求 |
| --- | --- | --- |
| 无提示提取、画简图、重建步骤 | 核心事实、关系或程序是否能从记忆恢复 | 问法清楚、范围有限；只回答术语不能支持机制理解；检查保持前不先复习本题关键答案 |
| 解释、预测并说明依据 | 概念关系、机制和因果链 | 预测之外观察必要理由；合理等价表达、公式或图均可，不用表达长度代替理解 |
| 正例/反例、成对对照 | 区分相近概念、必要条件与过度泛化 | 有意控制无关变化，改变能检验目标的条件；不是靠冷僻例外制造难度 |
| 诊断性选择题或关键检查题 | 快速决定继续讲还是针对性补讲 | 单一明确问题，选项同类且可信；来自候选错误的干扰项要能解释其诊断用途，不能一选就确诊 |
| 答案加理由，必要时报告不确定处 | 区分结论正确、理由错误、猜测或含糊表达 | 自信仅辅助追问优先级，不改变内容标准；不强迫每题填多阶信心表 |
| 错误解答分析、找第一个不成立步骤 | 推理监控、辨错与修复 | 错误解答明确作为待审材料；纠正后给准确模型；能识错不自动证明能从零完成同类任务 |
| 例题补全、逐步减少提示 | 新手把解释转成可执行步骤 | 先有必要讲解；去掉真正需要练的步骤，依据实际表现撤帮助，随后再安排独立任务 |
| 混合练习、自行选方法 | 识别题目结构，区分何时使用相近方法 | 先建立单项基础；混合有区分价值的题，不在标题预告每题方法，也不只随机混排无关内容 |
| 读图、计算、实验/项目、代码任务 | 把知识用于实际产出与验收 | 使用真实可读材料和足够条件，核查单位与约束；口头说会做不代替应有产出 |
| 陌生但相关的变式 | 迁移、适用边界和方法调整 | 说明实际改变的条件/表示/约束；只换名字、数字或复述措辞不自动支持迁移 |

在关键转折处用少量有诊断力的问题检查即可。选择题、开放题和实际任务各有适用目标；基础检索不因“认知层级低”失去价值，写了“分析/评价/创造”也不使题目自动高质量。

## 发题前验题

先自行作答，再从学生收到的题面核查以下事项。检查失败时先修题，不能让学生承担题目错误造成的无效劳动。

1. **范围与前提：** 对应本次目标和实际读取材料；先修已建立，或题内提供的是当前目标允许的背景。未知资料或未读图不能生成确定评分键。
2. **正确与可解：** 核算数字、单位、公式、符号、图表信息和条件一致性；程序或实验任务核查可行输入与可观察输出。信息不足若正是考点，事先把识别不足作为任务，而不是事后借口。
3. **答案集合：** 单一最佳答案题确有在明确条件下的最佳答案；开放题承认成立的多种方案与合理假设，固定必要标准。
4. **诊断区分：** 针对的错误规则是否会碰巧得到同一答案？会则调整条件或观察理由；如果仍无法区分，缩小本题能支持的结论。
5. **无关负担：** 阅读量、计算量、术语或图形细节确实服务目标；避开无意义陷阱、否定套否定和依靠猜作者意思的题目。目标本来是信息筛选时，可保留有据的相关/无关材料。
6. **线索泄漏：** 检查题干、选项长度/语法、标题、配图、开场摘要及相邻题是否泄露关键答案或方法。选项不能只剩一个看起来专业的答案。需多题独立证据时，检查前题及反馈是否替后题解题。
7. **反馈准备：** 对主要可能回答已有准确的修复解释与下一观察动作；以错误材料教学后，必须明确纠正，避免只展示错误说法后离开。
8. **观察边界：** 当前任务实际能检验内容、表达、应用、独立、保持、迁移中的哪些部分；所需时间与当前精力相称。

题目已发出后若发现歧义、错误答案键或缺资料，保留实际题目和原话，明确受影响的判断暂不成立，修正教学与题目后再取得所需证据。对原回答中独立成立的部分据实认可，不把教师缺陷记成学生知识错误。

自解和规则检查是必要质量控制，不能证明题目已得到效度验证。单个学生的少量聊天作答不能产生可靠的群体难度、区分度或信度统计；不编造“已校准题库”“诊断准确率”或掌握概率。

## 按回答选择下一步

先按 [判定规范](assessment.md#逐项判断学生实际表达) 核对实际作答，再选择最能消除当前不确定性或帮助修复的一步。不要在未看回答前排定一串追问题，或遇到错误一律再出更难的题。

| 实际观察 | 下一步 |
| --- | --- |
| 结论与必要理由完整正确 | 认可本题范围内的表现；按当前目标推进、做尚缺的边界任务或留真实延迟复测，不重复润色性重考 |
| 结论正确但理由未提供 | 只认可已观察到的结论；若理由是事前要求，补收理由；若原任务未要求理由，要验证机制就另发任务，不回溯判原选择题答错 |
| 结论正确但理由有核心错误 | 定位错误规则并补讲；选能排除该规则的新条件验证，不能让正确选项抵消错误理由 |
| 只选到某个干扰项 | 把它看作候选原因；先收简短理由或关键过程，区分概念、读题、运算、猜测和题目问题，不给学生贴稳定误解标签 |
| 指代、顺序或表述阻断判断 | 做中性澄清或允许画图/算式；需要组织帮助时如实归因，再区分表达和知识缺口 |
| 前置概念或程序负担阻断完成 | 直接补教并给适当例题/步骤支架，逐步重构；不用连续盲猜题代替教学 |
| 运算或执行局部出错而方法已成立 | 定点修正并取得实际正确产出；不笼统判整套概念不会，也不让关键结果错误通过 |
| 当前题面、来源或答案键有问题 | 先核查修题；限制证据结论，保留原话与更正关系 |
| 暂停、时间不足或疲劳 | 保存真实进展、未完成项与下一任务条件；继续不依赖该缺口的内容或暂停，未验证保持未验证 |

题目难度只能按已观察到的表现作相对调整，不能把一两题作答推断成精确能力参数。未发现问题也不等于已排除所有误解；优先覆盖尚无证据的必要条件。

## 巩固与复习

把练习安排成有反馈、可恢复、会再次提取的过程。诊断题负责帮助决定教什么，巩固题负责让相关知识或步骤再次被使用；一题可兼有作用，但不必强求每题同时完成所有目标。

- **先能理解和操作，再逐步减少帮助。** 新手面对复杂程序时，可从完整例题、解释关键步骤、补全步骤转向独立完成；按表现调整撤助速度。需要完整答案时直接给出，并如实保留辅助属性。
- **提取后给针对性反馈。** 先取得实际尝试，再指出正确模型、错误原因和下一练习。批量作答按原节奏集中反馈；若批次后题会暴露前题答案或反馈会污染后题，调整题序、延后反馈或明确其属于练习。
- **安排真实间隔后的再次使用。** 利用现有 continuation 和周复盘接续；根据既往提示依赖、遗忘表现、知识重要性与目标使用时间调整。优先沿用已确认安排，不规定所有知识统一在第1/3/7天复习，也不为本流程新建后台提醒。
- **按用途重复或变式。** 同题或同类题可用于检索、步骤熟练和纠错，但结论限于实际条件；需要排除特定误解或检验迁移时，改变有诊断意义的条件。新题要降低本题答案依赖，而非不断增加题面陌生度。
- **在有基础后交错相近任务。** 当目标包含选方法时，让学生在混合任务中判断何时用哪种方法，记录选择依据；不把主题随机混杂当成有效交错，也不让明显缺基础者靠高负荷猜测。
- **保持与迁移分开。** 经过真实间隔才有 delayed；进入陌生相关条件才可能有 transfer。刚看过答案、刚受提示或只生成了复习计划，都不能形成独立保持证据。此类归因按 assessment 执行。
- **达到本次目的后停止低价值重复。** 已有充分证据的内容不为完成题数重考；仍缺必要证据则保留或定点补测。题数、学习中答题流畅和当次正确率均不单独证明长期学习。

## 覆盖、记录与题目修订

章节题目组合按“原资料实质内容 × 要求的认知/操作任务”检查覆盖。依据原课程目标和真实考试范围决定抽样，不要求每页一道题或每项题数相同；未测内容保留未验证。高频练习一个小点，不能替代该章节其他定义、条件、读图、推导或方法。资料教学覆盖与测评覆盖分别核对。

沿用 [记录格式](record-format.md#命题用途与后续任务沿用-v1-字段)。实际 question 保存当时题面、要求与资源条件；feedback 简记主要用途、目标、观察到的理由、当前候选原因及结论边界；下一步保存需要补教或区分的内容。多视角仍只评价一次实际作答。备题或安排复习没有新作答时 evidence=[]。

来源改编、教师原创和真实学生错误分别标明。维护题目时使用实际作答或独立审题发现的问题作为依据；不能虚构试测人数或说某个未观察到的错误“学生经常犯”。重要或争议题可请实际可用的独立评阅者重新解题并检查来源，复核仍不代替课程要求的正式评审。

## 一个诊断题组的设计示例

以下为教师原创的均值示例，用于说明任务设计，不代表用户本人的表现，也不是必须每次完整执行的固定题组。假设已经讲过“均值=总和÷个数”，且任务要检查合并数据时的理解。

1. **独立诊断题：** “A组有2个数，均值为4；B组有6个数，均值为8。合并后的均值是多少？请说明依据。”正确合并总和为2×4+6×8=56，个数为8，均值为7；直接平均两组均值得6，按组内个数反向加权得5。题面只给问题，答案与候选解释不在作答前展示。
2. **按实际回答跟进：** 若学生只答6，先问其依据；不能单凭数值断言其稳定持有“所有组均值都直接平均”的规则。若确实如此解释，补讲总和与个数，再让学生重构。
3. **条件辨析：** “什么情况下，两组均值可以直接取算术平均得到合并均值？说明条件。”在两组都非空且均值定义如上时，组大小相等，或两组均值相等，都成立；只给“人数相等”作唯一完整答案会漏掉另一种情况。本题的标准应与公开要求一致。
4. **后续复测：** 按实际帮助与时间，另选不同组大小和均值的新任务，或在已有基础上用表格/实际合并数据场景检查使用；只换数值可支持相应程序练习，不自动宣称迁移。验证选择与提示条件另按 assessment 核查。

这里，必要改变是让正确合并规则与错误直接平均规则产生不同结果；并不是简单把数字变大或计算变长。每个后续任务都由已有回答和当前教学目的决定。

## 方法依据与实施边界

本规范采用成熟测评与教学研究中的原则，并将其转成针对本学习助手的执行规则。阶段表、验题清单与自动路由是实施设计，不是已经通过真实课堂效果试验的组合产品。
